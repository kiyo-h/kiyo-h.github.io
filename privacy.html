プライバシー ポリシー

gmailcheck は開発者本人の Gmail アカウントだけで使用する個人用ツールです。

  • Gmail API で、メールのヘッダ（差出人・件名・配信停止情報）とラベルを読み取り、ラベルを追加します。
  • 処理は利用者の PC 内だけで行い、取得したデータを第三者へ送信・共有しません。
  • 保存するのは前回の実行時刻だけで、メールの内容は保存しません。
  • Google API から取得した情報の利用は、Google API Services User Data Policy（Limited Use の要件を含む）に従います。
  • アクセス権は Google アカウントの「サードパーティ アクセス」からいつでも取り消せます。
